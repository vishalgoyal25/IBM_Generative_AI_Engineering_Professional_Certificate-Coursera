ARTIFICIAL INTELLIGENCE (AI)
│
├── MACHINE LEARNING (ML)  → "Learns patterns from data"
│   │
│   ├── SUPERVISED LEARNING (labeled data: X → y)
│   │   │
│   │   ├── REGRESSION → predict continuous values
│   │   │     Example: House price prediction
│   │   │     Algorithms: Linear Regression, Ridge, Lasso
│   │   │
│   │   └── CLASSIFICATION → predict categories
│   │         Example: Spam vs Not Spam
│   │         Algorithms: Logistic Regression, SVM, Decision Trees, Random Forest
│   │
│   ├── UNSUPERVISED LEARNING (no labels)
│   │   │
│   │   ├── CLUSTERING → group similar data
│   │   │     Example: Customer segmentation
│   │   │     Algorithms: K-Means, DBSCAN
│   │   │
│   │   └── DIMENSIONALITY REDUCTION → reduce features
│   │         Example: PCA for visualization
│   │
│   └── (Key Idea) → Manual feature engineering required
│
├── DEEP LEARNING (DL)  → subset of ML using Neural Networks
│   │
│   ├── NEURAL NETWORK FLOW:
│   │     Input → Layers → Prediction → Loss → Backpropagation → Weight Update
│   │
│   ├── CORE COMPONENTS:
│   │     Layers (Dense, CNN, RNN)
│   │     Activation (ReLU, Sigmoid)
│   │     Loss Functions
│   │     Optimizers (Gradient Descent)
│   │
│   ├── FRAMEWORKS (TOOLS):
│   │     ├── TensorFlow
│   │     │     └── Keras (high-level API)
│   │     └── PyTorch
│   │
│   └── (Key Idea) → Automatic feature learning
│
├── APPLICATION DOMAINS (using DL)
│   │
│   ├── COMPUTER VISION (CV)
│   │     Example: Image classification, Object detection
│   │     Model: CNN
│   │
│   └── NATURAL LANGUAGE PROCESSING (NLP)
│         Example: Chatbots, Translation, Text classification
│
├── TRANSFORMERS (Advanced DL Architecture)
│   │
│   ├── FLOW:
│   │     Text → Tokenization → Embeddings → Attention Layers → Output
│   │
│   ├── KEY IDEA:
│   │     Self-Attention (focus on important words)
│   │
│   └── REPLACES older RNN/LSTM in NLP
│
├── LARGE LANGUAGE MODELS (LLMs)
│   │
│   ├── BUILT USING:
│   │     Transformers + Massive Data + Huge Compute
│   │
│   ├── FLOW:
│   │     Text Data → Transformer Training → Pretrained Model
│   │
│   ├── EXAMPLES:
│   │     GPT, LLaMA, BERT
│   │
│   └── CAPABILITIES:
│         Text Generation, Q&A, Summarization, Coding
│
├── MODEL ADAPTATION LAYER
│   │
│   ├── FINE-TUNING:
│   │     Pretrained Model → Task-specific training
│   │
│   ├── PARAMETER-EFFICIENT METHODS:
│   │     LoRA, PEFT
│   │
│   └── INSTRUCTION TUNING:
│         Improves following human instructions
│
├── EMBEDDINGS (Core for Retrieval)
│   │
│   ├── FLOW:
│   │     Text → Embedding Model → Vector (numbers)
│   │
│   └── USE:
│         Similarity Search, Semantic Meaning
│
├── RAG (Retrieval-Augmented Generation)
│   │
│   ├── FLOW:
│   │     User Query
│   │        ↓
│   │     Convert to Embedding
│   │        ↓
│   │     Search Vector Database (FAISS, Pinecone)
│   │        ↓
│   │     Retrieve Relevant Documents
│   │        ↓
│   │     Pass to LLM
│   │        ↓
│   │     Generate Answer
│   │
│   └── (Key Idea) → Combines knowledge + generation
│
└── APPLICATION / ORCHESTRATION LAYER
    │
    ├── LANGCHAIN
    │     ├── Connects LLM + Tools + Memory + Retrieval
    │     ├── Builds pipelines (chains)
    │     └── Enables agents
    │
    ├── AGENTS
    │     LLM decides which tool to use
    │
    ├── TOOLS
    │     APIs, databases, search engines
    │
    └── MONITORING / EVALUATION
          Track performance, hallucination, accuracy

==================== MACHINE LEARNING (ML) ====================
"Learning patterns from data"

   ├── SUPERVISED LEARNING
   │     ├── Regression → predict numbers (house price)
   │     └── Classification → predict classes (spam detection)
   │
   ├── UNSUPERVISED LEARNING
   │     ├── Clustering → grouping (customer segments)
   │     └── Dimensionality Reduction → PCA
   │
   └── OUTPUT:
         Learned patterns (simple models)

        │
        │  (Limitation: manual features, limited complexity)
        ▼
==================== DEEP LEARNING (DL) ====================
"Advanced ML using Neural Networks"

   INPUT DATA
      ↓
   Neural Network (layers learn features automatically)
      ↓
   Prediction
      ↓
   Loss → Backpropagation → Weight update

   ├── REPLACES many ML algorithms when data is large
   ├── Handles complex data (images, text)
   └── BUILT USING:
         ├── PyTorch
         └── TensorFlow → Keras (simplified API)

        │
        │  (DL enables advanced architectures)
        ▼
==================== TRANSFORMERS ====================
"Specialized DL architecture for sequence understanding"

   TEXT
    ↓
   Tokenization
    ↓
   Embeddings (vector representation)  ◄────────────┐
    ↓                                               │
   Self-Attention (focus on important words)        │
    ↓                                               │
   Deep Layers                                      │
    ↓                                               │
   OUTPUT (next word / meaning)                     │
                                                    │
   └── KEY BREAKTHROUGH: Understand context better ─┘

        │
        │  (Scaling transformers → huge models)
        ▼
==================== LARGE LANGUAGE MODELS (LLMs) ====================
"Massive Transformer-based models"

   Massive Text Data
        ↓
   Transformer Training (DL)
        ↓
   Pretrained Model (GPT, BERT, LLaMA)

   ├── Capabilities:
   │     Text generation, Q&A, summarization, coding
   │
   └── STILL USES:
         ├── DL (training mechanism)
         ├── ML concepts (loss, optimization)
         └── Embeddings (vector meaning)

        │
        │  (LLMs need adaptation for real tasks)
        ▼
==================== MODEL ADAPTATION ====================
   ├── Fine-Tuning
   │     LLM + task data → specialized model
   │
   ├── LoRA / PEFT
   │     Efficient tuning (less compute)
   │
   └── Instruction Tuning
         Align with human prompts

        │
        │
        ▼
==================== EMBEDDINGS (BRIDGE BETWEEN ML & LLMs) ====================
"Text → Vector (numbers)"

   Text
    ↓
   Embedding Model (DL)
    ↓
   Vector Space

   ├── USED IN:
   │     ├── Similarity search (ML concept)
   │     ├── Clustering (ML reused!)
   │     └── Retrieval systems
   │
   └── CONNECTS:
         ML ↔ DL ↔ LLM

        │
        ▼
==================== RAG (Retrieval-Augmented Generation) ====================
"Combines ML retrieval + LLM generation"

   User Query
      ↓
   Convert to Embedding
      ↓
   Vector Search (ML similarity!)
      ↓
   Retrieve Documents
      ↓
   Pass to LLM
      ↓
   Generate Answer

   └── KEY INSIGHT:
         ML (search) + DL (LLM) working together

        │
        ▼
==================== GEN AI SYSTEMS ====================
"End-user applications"

   ├── LangChain
   │     ├── Connects LLM + tools + memory + retrieval
   │     ├── Builds pipelines (chains)
   │     └── Enables agents
   │
   ├── AGENTS
   │     LLM decides actions (tool usage)
   │
   ├── TOOLS
   │     APIs, DBs, search engines
   │
   └── MONITORING
         Evaluate outputs (ML metrics reused)

1. ML concepts (loss, optimization, similarity) are used everywhere
2. DL is just advanced ML
3. Transformers are a type of DL
4. LLMs are scaled Transformers
5. Embeddings connect ML (vectors) with LLMs
6. RAG combines ML retrieval + LLM reasoning
7. LangChain = orchestration layer, not intelligence
